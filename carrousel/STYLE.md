# Стиль постов @elena_myrlen

## Тексты
- Обращение на «вы», для всех (без женских окончаний в обращении).
- Аудитория: тревожность в отношениях, недоверие, чувство вины, «я плохой / не такой», сложно сказать «нет».
- Формула, которая работает: привычная фраза → её скрытый смысл («„Я просто такой человек“ чаще всего значит „я не хочу ничего менять“»).
- Каждый слайд понятен с первого прочтения, без абстрактных афоризмов.
- Избегать: конструкции «это не X, это Y»; клише («бережно», «в своём темпе», «с этим можно работать»); повторов слов.
- Только короткое тире «–», длинное «—» не использовать.
- Призыв в фирменном тоне: «Хотите – соглашайтесь, хотите – спорьте… А хотите – приходите на консультацию». Запись: ссылка в шапке профиля / WhatsApp.

## Оформление каруселей
- Формат 1080×1350 (4:5).
- Шрифт: Onest (жирный для заголовков, обычный для текста), файл `fonts/Onest.ttf`.
- Обложка: фото Елены, крупный белый заголовок.
- Слайды: кремовый фон #F7F2EA, фраза чёрным #1C1917, расшифровка розово-красным #B7545E, ник `@ELENA_MYRLEN` внизу (#A88F7A), стрелка «листай» справа.
