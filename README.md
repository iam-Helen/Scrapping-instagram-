# Мониторинг Instagram → Telegram

Каждую неделю этот проект собирает публичные публикации аккаунтов и хештегов твоей ниши, находит те, которые работают лучше всего, и присылает отчёт в Telegram.

- **Никакой аккаунт Instagram не используется**: публичные данные собирает [Apify](https://apify.com) на своих серверах. Твоему аккаунту ничего не грозит.
- **Всё работает само** и бесплатно благодаря GitHub Actions (по умолчанию в понедельник утром). Компьютер не нужно держать включённым.

## Что входит в отчёт

- 🔥 **Публикации, которые «выстреливают»**: набрали минимум в 1,5 раза больше реакций, чем обычно для своего аккаунта. Это лучший признак темы или хука, которые работают.
- 🏆 **Больше всего реакций**: публикации с наибольшим количеством лайков и комментариев.
- 🎬 **Форматы**: Reels, карусели или фото, со средним числом реакций для каждого.
- 🏷️ **Хештеги**, которые используют лучшие публикации.

После каждого запуска также сохраняется таблица **CSV** (открывается в Excel) и файл JSON. Они хранятся 30 дней во вкладке *Actions* на GitHub.

## Установка (около 10 минут, один раз)

### 1. Создать аккаунт Apify (бесплатно)

1. Зарегистрируйся на <https://console.apify.com/sign-up>. Банковская карта не нужна.
2. Скопируй свой API-ключ на странице <https://console.apify.com/settings/integrations>.

Бесплатный план даёт **5 $ кредита в месяц**. Когда кредит закончится, Apify просто остановится до следующего месяца: неожиданных счетов не будет.

### 2. Создать Telegram-бота

1. В Telegram напиши **@BotFather**, отправь `/newbot` и следуй инструкциям. Он выдаст тебе **токен**.
2. Отправь любое сообщение своему новому боту, например «привет».
3. Узнай номер своего чата:
   ```bash
   pip install requests
   TELEGRAM_BOT_TOKEN=твой_токен python telegram_chat_id.py
   ```

### 3. Сохранить ключи в GitHub, чтобы они остались приватными

В репозитории на GitHub открой **Settings → Secrets and variables → Actions → New repository secret** и добавь:

| Название             | Значение                            |
|----------------------|-------------------------------------|
| `APIFY_TOKEN`        | API-ключ Apify                      |
| `TELEGRAM_BOT_TOKEN` (или `TG_BOT_TOKEN`) | токен от @BotFather |
| `TELEGRAM_CHAT_ID` (или `TG_CHAT_ID`) | номер, полученный на шаге 2 |

⚠️ Никогда не вставляй эти ключи в файлы репозитория или в сообщения.

### 4. Выбрать, что отслеживать

Отредактируй [`config.yaml`](config.yaml): добавь аккаунты (имя или ссылку на профиль) и хештеги своей ниши.

### 5. Проверить

Во вкладке **Actions** на GitHub открой **Veille Instagram** и нажми **Run workflow**. Через несколько минут отчёт придёт в Telegram.

## Стоимость

Инструмент `apify/instagram-scraper` на бесплатном плане стоит около **0,0027 $ за каждую собранную публикацию** (цены на ноябрь 2026).

| Пример                                          | За запуск      | В месяц (раз в неделю) |
|-------------------------------------------------|----------------|------------------------|
| 15 аккаунтов + 3 хештега × максимум 12 публикаций | ≈ 0,58 $ макс. | ≈ 2,30 $               |

Фильтр «последние X дней» часто уменьшает реальное число публикаций. Лимит `budget_max_usd` в файле `config.yaml` (по умолчанию 1 $ за запуск) останавливает Apify, если он достигнут. Еженедельный мониторинг разумного размера укладывается в бесплатный кредит.

## Запуск на своём компьютере (необязательно)

```bash
pip install -r requirements.txt
export APIFY_TOKEN=...                     # не добавлять в репозиторий
python veille.py --dry-run                 # показывает отчёт, не отправляя его
python veille.py --fichier sorties/brut_….json --dry-run   # повторный анализ без оплаты
python -m pytest                           # тесты
```

## Правила использования

- Проект собирает только **публичные данные**. Используй их, чтобы понять, какие темы, форматы и хуки работают, а не чтобы перепубликовывать чужой контент (авторское право).
- **Персональные данные (GDPR)**: комментарии в отчёте не используются, а выгрузки автоматически удаляются через 30 дней.
